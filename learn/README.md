# learn/

`pending/` (gitignored) holds candidates the LEARN phase writes after a run: which threading
rule fired, which data requests recurred, what VERIFY stripped. `/casa:learn` shows them to the
analyst; only on approval is an entry appended to `skills/standards/references/lessons.md`.
Approved and discarded notes move to `archive/` (gitignored). `/casa:learn --list`,
`--approve <file>` and `--discard <file>` work headlessly.
